OpenAI 开源 Codex Security CLI，扫描与修复漏洞能力下沉到本地与 CI/CD

OpenAI 于 7 月 28 日在 X 平台宣布开源 Codex Security CLI 与 TypeScript SDK（Apache 2.0，包名 @openai/codex-security）。该工具可扫描代码仓库、按 Git diff 增量审查、跨多次运行追踪问题、生成 SARIF/CSV/JSON 报告，并在 CI/CD 中通过 `--fail-on-severity` 强制质量门禁。Codex Security CLI 与 3 月推出的研究预览版 Codex Security（即内部代号 Aardvark）共享底座，默认使用 gpt-5.6-sol 模型；当前仍为有限 Beta，源代码开放但底层扫描器需获批访问。
